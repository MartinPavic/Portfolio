## Overview

A static site deployed on Cloudflare Pages, with all content stored as MDX and YAML in the repository.

## Highlights

- Content collections validated with Zod schemas at build time
- Self-hosted fonts and no framework runtime for fast loads
- Accessible, responsive, and respectful of reduced-motion preferences
