## Overview

The thesis, "Permissioned blockchain and distributed ledger technologies with smart contracts", is implemented on Hyperledger Fabric.

## What it does

- Fungible tokens represent messroom points
- Non-fungible tokens represent rector's awards
- Both token types are implemented as smart contracts, with an Angular and Node.js application on top
